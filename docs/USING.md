# Using Vitalog

## A person and a lab panel

Create a profile with the person’s name. Open a panel, such as a lipid panel, and enter each value with the low and high figures printed on that report. Vitalog flags a value against those figures. The flag is a label, not a diagnosis.

## A photo or PDF

Import the file from the device. Vitalog reads the text on the device and proposes matches. Nothing is stored until you save. Check the values and the ranges before that save.

## Lock

Turn on the app lock in Settings and set a PIN. Leaving the app locks it. The same PIN opens it. A wrong PIN is rejected. Biometrics can be added after the PIN exists. The PIN remains the fallback.

## Backup, wipe, restore

Save an encrypted backup from Settings. Keep the recovery key with the backup file. Vitalog cannot reconstruct that key later.

Wipe removes the record on this device. Restore brings back the profiles and results from the backup you choose. A backup file you copied elsewhere is not deleted by the wipe. Delete that copy yourself.

## Reference lists

Settings can refresh the test catalogue and the medicine-name list. Those downloads are published lists. They are not this person’s results.

## Help

Help in Settings can send a message to BSOC at outreach@bsoc.space. Send only what you are willing to have read. Do not include a lab report unless you mean to.
